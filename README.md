
# Programming for Problem Solving (PPS) - R25 Semester 1

This repository contains my C programming lab exercises, practice problems, and assignments from my 1st Semester R25 PPS coursework.

## About This Repository
I am using this space to practice problem-solving, strengthen my logic building, and track my progress as I learn the fundamentals of C programming.

## Topics Covered
* **Basics of C:** Data types, variables, operators, and input/output functions
* **Control Flow:** Conditional statements (`if-else`, `switch`) and loops (`for`, `while`, `do-while`)
* **Arrays & Strings:** 1D and 2D arrays, matrix operations, and string handling
* **Functions & Recursion:** Modular programming and recursive problem solving
* **Pointers & Structures:** Memory addresses, dynamic memory allocation, and user-defined data types
* **File Handling:** Reading from and writing to files

## How to Run the Programs
1. Open your terminal or command prompt.
2. Compile the C file using GCC:
   ```bash
   gcc filename.c -o output
3. Run the compiled program:
   bash
   ./output
   (On Windows, use **output.exe**)
